# 03 分类器与特征工程（人机轨迹区分）

## 一、目标

用机器学习区分「人工轨迹」与「机器生成轨迹」，反过来验证轨迹生成是否够「像人」。

---

## 二、样本

- **人工样本**：`human_drag_samples.json` 30 条（真人拖动采集），label=1；
- **生成样本**：`generated_tracks.jsonl` 400 条（8 变体 × 50），仅 combo 变体用于分类器训练。

> 人工样本建议补到 **40–50 条** 再上 RandomForest（当前 30 条，AdaBoost 足够）。

---

## 三、特征工程

### 全局特征（8 个）

- 总时长、总位移、平均速度、峰值速度、dt_p50/dt_p90、加减速统计等。

### 时间分段特征（24 个，核心创新）

把整条轨迹按时间切成 10 段（seg0–seg9），提取**切换/波形**类特征：

| 特征 | 含义 | 人机差异关键 |
|---|---|---|
| `accel_sign_changes` | 加速度符号翻转次数 | 人的切换频繁 |
| `accel_sign_change_rate` | 翻转频率 | 同上 |
| `reacceleration_count` | 二次加速次数 | **机器=0，人≥1** |
| `turn_points_density` | 转折点密度 | 人≈0.6，机器≈0.2 |
| `speed_plateau_ratio` | 速度平台占比 | 机器过高 |
| `speed_local_maxima/minima` | 局部极值数 | 人的双峰结构 |
| `reversal_count` | 反向次数 | 人的末端回拉 |
| `decel_smoothness` | 减速平滑度 | |
| `pre_release_micro` | 释放前微调 | **人=0**（旧实现方向错，已修正） |
| `last_200ms_*` | 最后 200ms 行为 | 释放阶段指纹 |
| `seg0-9_speed_p50` | 各段速度中位数 | 波形形状 |
| `seg0-9_dt_mean` | 各段时间间隔均值 | |

---

## 四、特征指纹结论

### 人工样本稳定指纹

- `dt_p50` 始终 **5.0–5.2ms**（极强指纹，机器难伪造的采样抖动）；
- `pre_release_micro = 0`（人释放前没有多余微调）。

### 机器（combo）暴露的马脚

分类器结论（稳定）：

1. **整数量化噪声缺失**（人的 dx 被采样设备量化到 ~0.5px 网格）；
2. **单峰波形**（`reacceleration_count=0`，人至少二次加速）；
3. **转折点密度过低**（~0.2 vs 人 ~0.6）；
4. **速度平台过高**（机器匀速段太长）。

> feedback 变体全部修复这 4 点 → 线上 5/5。

---

## 五、分类器实现（不走 sklearn）

环境无 sklearn，用**依赖无关的 AdaBoost over stumps**：

- `SimpleStump`：单特征阈值弱分类器；
- `train_forest`：AdaBoost，8 轮；
- `forest_predict`：alpha 加权投票。

### 过拟合教训

- 早期 100% LOOCV 是**过拟合**（特征与标签在训练里泄漏）；
- 改为**单特征判别力**做重要性（accuracy−0.5），稳健。

---

## 六、为什么要这样设计

- 风控模型本质是判别式模型，机器轨迹要骗过它，就得让**分类器也分不清**；
- 特征工程 = 把「风控在意的形态差异」显式化，用分类器当「镜像风控」做离线打分；
- **标签纪律**：人工=1 是唯一 gold，线上判定只作贡献证据，绝不当训练标签。
